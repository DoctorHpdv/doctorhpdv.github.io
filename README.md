# Spectrum-GS project page

This folder contains a static academic project page for Spectrum-GS. It can be published directly with GitHub Pages and does not require a build step.

## Files

- `index.html`: page content
- `styles.css`: responsive visual styling
- `script.js`: interactive comparison sliders
- `assets/pipeline.png`: web-ready pipeline figure
- `assets/Spectrum-GS.pdf`: compressed paper PDF for web download
- `assets/videos/`: two browser-ready cross-scale rendering videos and poster images
- `assets/comparisons/`: Momentum-GS and Spectrum-GS frames for two visual comparisons
- `.nojekyll`: asks GitHub Pages to serve the files as-is

## Publish with GitHub Pages

1. Create a public GitHub repository, for example `spectrum-gs`.
2. Upload everything inside this folder to the repository root.
3. Open `Settings` → `Pages`.
4. Under `Build and deployment`, select `Deploy from a branch`.
5. Select branch `main` and folder `/(root)`, then save.
6. The site will appear at `https://YOUR-USERNAME.github.io/spectrum-gs/`.

## Edit later

Edit text in `index.html`, replace files in `assets/`, and commit the changes. GitHub Pages will redeploy automatically.
